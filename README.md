# TSC Print

Небольшое веб-приложение для подготовки и печати этикеток на принтерах TSC. Браузер формирует команды TSPL, а Flask-сервис последовательно отправляет их в принтер через `/dev/usb/lp0`.

## Возможности

- Печать включительного диапазона номеров в прямом и обратном порядке.
- Ввод собственного списка номеров.
- Два шаблона этикеток: текстовый и штрихкод с номером.
- Отправка TSPL в TSC через Docker Compose.
- Нормализация TSPL до CRLF и обязательный завершающий CRLF для каждого задания.
- Последовательная запись заданий в один принтер и диагностические логи с идентификатором задания.

## Требования

- Linux-хост с Docker Engine и Docker Compose.
- Принтер TSC, подключённый к хосту как `/dev/usb/lp0`.

Проверьте наличие устройства перед запуском:

```bash
ls -l /dev/usb/lp0
```

Compose пробрасывает это устройство в контейнер. Если путь отсутствует на хосте, Docker Compose не сможет создать контейнер.

## Первый запуск

```bash
git clone https://github.com/DrCramer/tsc-print.git
cd tsc-print
docker compose up -d --build
```

Откройте приложение в браузере:

```text
http://localhost:9090
```

Кнопка **«Печать»** отправляет сформированное задание в принтер. Копирование TSPL в буфер обмена работает отдельно и не требует подключения принтера.

## Обновление на сервере через GitHub

Подключитесь к серверу и перейдите в каталог, куда был клонирован проект:

```bash
cd ~/tsc-print
git status --short
git branch --show-current
```

Убедитесь, что рабочая ветка — `main`, а `git status --short` не показывает локальные изменения. Затем получите обновление и пересоберите контейнер:

```bash
git pull --ff-only origin main
docker compose up -d --build
docker compose ps
```

Посмотреть логи приложения:

```bash
docker compose logs --tail=100 tsc-print
```

Для просмотра новых сообщений в реальном времени:

```bash
docker compose logs -f tsc-print
```

Проверить веб-интерфейс и API можно с самого сервера:

```bash
curl -f http://127.0.0.1:9090/
curl -i -X POST http://127.0.0.1:9090/print \
  -H 'Content-Type: application/json' \
  -d '{"tspl":"SIZE 43 mm, 24 mm\nGAP 2 mm, 0 mm\nCLS\nTEXT 48,180,\"3\",0,3.5,3.5,\"TEST\"\nPRINT 1"}'
```

Успешный ответ API содержит `"ok": true` и `job_id`. Физическую печать этого тестового запроса выполняйте только если этикетка `TEST` нужна.

### Если на сервере есть локальные изменения

Не используйте `git reset --hard`: сначала выясните, какие файлы изменены. Если это ваши временные правки, отложите их, обновите проект и при необходимости верните:

```bash
git stash push -m "server-local-before-update"
git pull --ff-only origin main
docker compose up -d --build
git stash list
```

Если Docker доступен только через `sudo`, добавьте `sudo` к командам `docker compose`. Команды `git` запускайте от пользователя, которому принадлежит каталог проекта, без `sudo`.

## Диагностика

### Устройство принтера не найдено

Проверьте, что принтер подключён и хост создал устройство:

```bash
ls -l /dev/usb/lp0
docker compose ps
docker compose logs --tail=100 tsc-print
```

После подключения принтера повторно запустите контейнер:

```bash
docker compose up -d
```

### Принтер не печатает или задание завершилось ошибкой

Проверьте состояние принтера, подключение USB и логи сервиса. Каждое задание получает короткий `job_id`; сервер пишет в лог ожидание и получение блокировки, открытие устройства, запись, закрытие и ошибку, если она возникла.

### Порт 9090 занят

В `docker-compose.yml` порт опубликован как `9090:9090`. Освободите этот порт или измените только левую часть mapping, например `9091:9090`, затем пересоздайте сервис:

```bash
docker compose up -d --build
```

## Разработка и проверка

Сборка и запуск:

```bash
docker compose up -d --build
```

Просмотр конфигурации и логов:

```bash
docker compose config
docker compose logs -f tsc-print
```

Остановка сервиса:

```bash
docker compose down
```

Приложение использует один Gunicorn worker с несколькими потоками. Общая блокировка сериализует доступ к принтеру внутри этого процесса. При увеличении числа workers блокировку нужно заменить межпроцессной блокировкой или отдельной очередью печати.
